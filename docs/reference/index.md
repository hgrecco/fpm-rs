# API reference

The [Python API](python/index.md) is the recommended high-level interface for
NumPy workflows. Its pages are generated by mkdocstrings from the installed
`fpm_rs` package, its `.pyi` type surface, and public docstrings; signatures are
not copied manually into Markdown.

The [Rust API](rust.md) is generated by native rustdoc for the public `fpm-rs`
crate. Use it for lower-level integrations, algorithm development, lazy
measurements, custom callbacks, and performance-sensitive code.

Both surfaces document the single API intended for the first public release.
