# Contributing

Build, test, documentation, API, and release conventions are maintained in the
[contributor and development guide](docs/development/index.md). Consult the
sections relevant to the change and follow the repository-level
[`AGENTS.md`](AGENTS.md) plus any scoped `AGENTS.md` in the affected subtree.

Use an issue or discussion to establish scope when a change would alter public
scientific conventions, serialized formats, or the Rust/Python API boundary.
